## [1.0.0] - 2026-09-22

### Added
- **Interactive Portfolio Carousel**: Horizontal project carousel with category filtering (*Modular Kitchen, Living Room, Bedroom, Wardrobes, Home Office*).
- **Lightbox Modal View**: Detailed project view with category tags, project location, custom description, and quick WhatsApp enquiry button.
- **Service Material Specs Modal**: Technical dialogs for each service showcasing core materials, hardware brands (*Blum, Hafele, Hettich*), finishes, warranty details, and turnaround timelines.
- **Before / After Transformation Slider**: Interactive drag handle enabling side-by-side comparison of bare civil site photos against finished VSK modular interiors.
- **WhatsApp Floating Quick Chat Widget**: Multi-option quick-action popup card for fast consultation and site measurement requests.
- **Consultation Form**: Online request form with live validation, toast notification engine, and optional WhatsApp redirect.
- **Project Setup & Documentation**: `.gitignore`, `.editorconfig`, `README.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, and `LICENSE`.
